# 🧪 实验室配液约束求解器（Lab Solution Solver）

录入多种**库存溶液**的浓度、密度、可用体积与单位，以及**目标配方**的总体积和各溶质目标浓度；
服务端自动统一单位，并通过**线性规划**求解同时满足以下约束的取液方案：

- **体积守恒**：各库存液用量（＋稀释剂补量）= 目标总体积
- **浓度约束**：每种溶质的最终浓度恰好等于目标浓度
- **库存上限**：任一库存液用量不超过其可用体积

返回每种库存液的用量、稀释剂补量，或给出**明确的不可行原因**（如某溶质库存总质量不足、
体积上限与配比相互冲突等）。方案可保存到 SQLite 并随时载入重新计算。

技术栈：**Python · FastAPI · SQLite · 原生 HTML/CSS/JavaScript · SciPy(HiGHS LP)**，无前端框架、无 Node 构建。

## 🧑‍🔬 使用说明

页面分左右两栏：

**左侧 — 输入**

1. **目标配方**：填写总体积及单位，添加目标溶质的名称、目标浓度、浓度单位
   （摩尔浓度需填摩尔质量）。
2. **库存溶液**：为每种库存液填写名称、可用体积及单位、可选密度（`%(w/w)` 时必填），
   并添加其溶质组分及浓度。**组分留空的库存液视为纯稀释剂**（如纯水）。
   同一库存液可含多种溶质，用于建模预混液（如 50× TAE）。
3. **求解选项**：
   - **允许额外纯水补足体积**：库存稀释剂不够时，是否允许用不限量的额外稀释剂补齐总体积；
   - **允许杂溶质**：默认禁用含有目标配方之外溶质的库存液，防止意外带入杂质；
   - **优化策略**：
     - *取液总量最少*：优先使用浓储液，取液体积最小（实验室常用，移液相对误差小）；
     - *稀释剂用量最少*：尽量多地使用库存液，额外补水最少。
4. 点击 **▶ 求解取液方案**；填写名称后可 **💾 保存方案**。

**右侧 — 结果 / 已保存方案**

- 可行：列出每种库存液用量、额外稀释剂补量、合计体积，以及各溶质的
  **目标浓度 / 实际浓度 / 相对误差**核验表。
- 不可行：列出明确原因（溶质在库存中不存在、库存总质量不足、库存总体积不足、
  多溶质配比与体积上限冲突等）。
- 已保存方案可 **载入并计算**（恢复全部输入后自动重新求解）或删除。

### 支持的单位

| 量 | 单位 |
|---|---|
| 体积 | `mL`、`L`、`µL` |
| 浓度（质量/体积） | `mg/mL`、`g/L`、`mg/L`、`µg/mL`、`g/100mL`、`%(w/v)` |
| 浓度（质量/质量） | `%(w/w)`（需密度） |
| 摩尔浓度 | `mol/L`、`mmol/L`（需摩尔质量 g/mol） |
| 密度 | `g/mL`、`g/cm³`、`kg/m³`、`kg/L`、`g/L` |

服务端统一换算为内部单位（mg / mL）后求解，结果再按用户单位回算展示。

## 📐 数学模型

变量 `xᵢ` 为第 `i` 个库存液的取用量（mL），`C[s,i]` 为其溶质 `s` 浓度（mg/mL），
`V` 为目标总体积，`Mₛ` 为溶质 `s` 的目标质量（=目标浓度×V）：

```
质量守恒(浓度约束)   Σ_i C[s,i]·xᵢ = Mₛ              ∀ 目标溶质 s
体积守恒             Σ_i xᵢ ≤ V   （差额由补充稀释剂补齐）
                     或 Σ_i xᵢ = V   （不允许补水时）
库存上限             0 ≤ xᵢ ≤ avail_i
```

求解前先做预检（各溶质库存总质量是否足够、总体积是否足够、是否存在杂溶质），
不可行时直接给出可读原因；预检通过后用 SciPy 内置的 **HiGHS 线性规划求解器**求解，
并贪心精简取用的库存液种类。

> 说明：本模型假设混合体积可加、稀释剂为纯溶剂（贡献体积、不贡献溶质）。

## 🔌 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/solve` | 求解；可行返回用量/补水/浓度核验，不可行返回 `{feasible:false, reasons:[...]}` |
| GET | `/api/plans` | 已保存方案列表 |
| POST | `/api/plans` | 保存（按名称 upsert，保存时自动重算） |
| GET | `/api/plans/{id}` | 读取方案（含完整输入与结果） |
| DELETE | `/api/plans/{id}` | 删除方案 |
| GET | `/health` | 健康检查 |
